## Key Concepts Practiced

### Two Pointers
I practiced using two pointers to scan and compare characters efficiently.

Examples:
- Merge Strings Alternately
- Is Subsequence

### Sliding Window
I used the sliding window technique to find the longest substring without repeating characters.

### Stack
I used a stack to solve the Valid Parentheses problem by matching opening and closing brackets in the correct order.

### Hash Map
I practiced using hash maps to store character values and track previously seen characters.

### Greedy
I used a greedy approach for converting integers into Roman numerals by processing values from largest to smallest.

## What I Learned

- How to scan and manipulate strings efficiently.
- When to use two pointers for string problems.
- How sliding window works for substring problems.
- How a stack can be used for bracket validation.
- How to choose an appropriate data structure based on the problem.
- How to keep solutions simple while maintaining good time complexity.

## Challenges

The main challenge was understanding when to use each technique.  
Sliding Window and Stack-based problems required more practice, but solving them helped me understand the patterns better.

## Complexity

Most solutions were designed with efficient time complexity, generally **O(n)**, with additional space depending on the data structure used.
